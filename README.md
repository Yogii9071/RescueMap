🚨 RescueMap – Disaster Management Android App
RescueMap is a full-featured Android application designed to assist users during disasters by offering real-time location tracking, rescue agency discovery, emergency support, and critical alerts — all from one intuitive platform.

🌟 Features
🗺️ Interactive Google Maps Integration – View your current location and nearby rescue agencies on a live map

🔍 Search and Filter Agencies – Quickly locate rescue services based on area or service type

📡 Real-Time Alerts & Weather Info – Get live updates on disasters, emergency broadcasts, and weather alerts

🆘 Emergency Help Button – Instantly request help or alert authorities

👤 Profile Dashboard – Manage user info, view emergency contacts, and access settings

📲 Modern UI – Built using Material Design for a clean, user-friendly experience

🔐 Secure Login (Firebase Auth) – Role-based access for users and responders

🛠️ Tech Stack
Kotlin & XML – Core Android development

Android Studio – IDE

Google Maps SDK – Map integration and location services

Retrofit – RESTful API communication

Firebase Auth – User authentication

Material Components – UI/UX consistency

Shared Preferences – Local storage for user data
